---
name: Session detail visual direction
description: Approved visual direction for the EasyEdu student session detail screen.
---

Use the Modern Cards direction for the student session detail experience: an aqua session hero, prominent schedule/status, elevated white cards, teal icon treatments, numbered lesson rows, and warm teacher feedback.

**Why:** The user explicitly selected this option after comparing the current screen with several distinct visual concepts.

**How to apply:** Keep future refinements consistent with this friendly, scannable direction. Preserve real data and existing actions; lesson summaries should lead with type and title rather than displaying extra descriptive copy in the collapsed list.
