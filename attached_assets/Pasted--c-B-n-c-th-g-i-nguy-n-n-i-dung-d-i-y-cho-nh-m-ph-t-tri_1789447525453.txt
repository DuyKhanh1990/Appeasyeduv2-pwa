Được. Bạn có thể gửi nguyên nội dung dưới đây cho nhóm phát triển app web PWA.

API contract cho deeplink thông báo giao nội dung
1. Lấy danh sách thông báo
Nếu PWA dùng session web
GET /api/notifications

Gửi kèm cookie đăng nhập:

fetch("/api/notifications", {
  credentials: "include",
});

Mỗi notification có dạng:

{
  "id": "notification-uuid",
  "title": "Thông báo giao nội dung",
  "content": "Giáo viên vừa giao nội dung...",
  "category": "content",
  "referenceId": "class-uuid",
  "referenceType": "class",
  "isRead": false,
  "createdAt": "2026-09-15T04:00:00.000Z",
  "deeplink": {
    "screen": "Calendar",
    "params": {
      "date": "2026-09-15",
      "sessionId": "class-session-uuid",
      "classId": "class-uuid"
    }
  }
}

Đánh dấu đã đọc:

PATCH /api/notifications/:id/read

Đánh dấu tất cả đã đọc:

PATCH /api/notifications/read-all

Nếu PWA dùng API JWT mobile
GET /api/mobile/student/notifications?limit=50&offset=0
Authorization: Bearer <JWT>

Response:

{

2. Quy tắc điều hướng
App không tự suy luận màn hình từ tiêu đề hoặc nội dung thông báo. Luôn đọc:

const { screen, params = {} } = notification.deeplink || {};

Trường hợp có bài học hoặc có cả bài học + BTVN
Server trả:

{
  "screen": "Calendar",
  "params": {
    "date": "2026-09-15",
    "sessionId": "class-session-uuid",
    "classId": "class-uuid"
  }
}

PWA cần:

Mở màn hình Lịch.
Chuyển đến ngày date.
Tìm và làm nổi bật buổi có sessionId.
Nếu không tìm thấy sessionId, có thể dùng classId để tìm buổi trong ngày.
Ví dụ:

if (screen === "Calendar") {
  navigate("/my-space/calendar", {
    date: params.date,
    sessionId: params.sessionId,
    classId: params.classId,
  });
}

Nếu dùng URL:

/my-space/calendar?date=2026-09-15&sessionId=class-session-uuid&classId=class-uuid

Trường hợp chỉ có BTVN
Server trả:

{
  "screen": "Assignments",
  "params": {
    "date": "2026-09-15",
    "classId": "class-uuid"
  }
}

PWA cần mở:

/my-space/assignments?date=2026-09-15&classId=class-uuid

Ví dụ:

if (screen === "Assignments") {
  navigate("/my-space/assignments", {
    date: params.date,
    classId: params.classId,
  });
}

3. API lấy danh sách BTVN cho web PWA
Nếu PWA dùng endpoint web:

GET /api/my-space/assignments/student

Các tham số:

month=2026-09
classId=class-uuid

Ví dụ:

GET /api/my-space/assignments/student?month=2026-09&classId=class-uuid

Hoặc lọc theo khoảng ngày:

GET /api/my-space/assignments/student?dateFrom=2026-09-15&dateTo=2026-09-15&classId=class-uuid

Các tham số khác:

status=all|submitted|pending
itemType=all|BTVN|exam
page=1
pageSize=50

Response:

{
  "rows": [
    {
      "classSessionId": "class-session-uuid",

Fallback bắt buộc
Nếu có classId nhưng không có dòng nào khớp lớp đó:

Không được hiển thị màn hình “Không có bài tập”.

Thay vào đó:

Giữ bộ lọc ngày/tháng.
Bỏ riêng bộ lọc classId.
Hiển thị các bài tìm được trong ngày/tháng đó.
Ví dụ:

let rows = await fetchAssignments({
  date: params.date,
  classId: params.classId,
});
if (rows.length === 0 && params.classId) {
  rows = await fetchAssignments({
    date: params.date,
  });
}

4. Nếu PWA đang dùng endpoint mobile
Endpoint mobile là:

GET /api/mobile/student/assignments
Authorization: Bearer <JWT>

Endpoint này hiện hỗ trợ:

month=2026-09
dateFrom=2026-09-15
dateTo=2026-09-15
status=all|submitted|pending
className=IELTS 10
itemType=all|BTVN|exam
page=1
pageSize=50

Lưu ý: endpoint mobile hiện dùng className, chưa dùng classId để lọc BTVN. Nếu PWA đang gọi endpoint này thì nhóm PWA cần:

Dùng className theo contract hiện tại; hoặc
Chuyển sang /api/my-space/assignments/student nếu dùng web session; hoặc
Trao đổi để bổ sung classId vào endpoint mobile.
Tóm tắt logic cần sửa ở PWA
switch (notification.deeplink?.screen) {
  case "Calendar":
    // date + sessionId + classId
    openCalendar({
      date: params.date,
      sessionId: params.sessionId,
      classId: params.classId,
    });
    break;
  case "Assignments":
    // date + classId
    openAssignments({
      date: params.date,
      classId: params.classId,
    });
    break;
  default:
    // Không điều hướng
    break;
}
