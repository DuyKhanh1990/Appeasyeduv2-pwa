Đã bổ sung API cho phía học viên/phụ huynh và chuẩn hóa luồng API cho staff PWA.

1. Học viên/phụ huynh lấy mã QR
Endpoint
GET /api/mobile/student/attendance-qr

Header
Authorization: Bearer <JWT_TOKEN>

JWT lấy từ API đăng nhập mobile:

POST /api/mobile/auth/login

Học viên gọi API
Không cần truyền studentId:

GET /api/mobile/student/attendance-qr

Học viên chỉ nhận được mã QR của chính mình.

Phụ huynh gọi API
Không truyền studentId để lấy mã QR của tất cả con được liên kết:

GET /api/mobile/student/attendance-qr

Hoặc lấy QR của một con cụ thể:

GET /api/mobile/student/attendance-qr?studentId=<STUDENT_ID>

Nếu studentId không thuộc tài khoản phụ huynh, API trả 403.

Response
{
  "isParent": true,
  "students": [
    {
      "student": {
        "id": "student-uuid",
        "code": "HV-141",
        "fullName": "Nguyễn Thu Hiền 123"
      },
      "qr": {
        "payload": "WJ8Fzv...raw-token...",
        "token": "WJ8Fzv...raw-token...",
        "createdAt": "2026-09-19T01:45:00.000Z"
      }
    }
  ]
}

Với tài khoản học viên:

{
  "isParent": false,
  "students": [
    {
      "student": {
        "id": "student-uuid",
        "code": "HV-141",
        "fullName": "Nguyễn Thu Hiền 123"
      },
      "qr": {
        "payload": "WJ8Fzv...raw-token...",
        "token": "WJ8Fzv...raw-token...",
        "createdAt": "2026-09-19T01:45:00.000Z"
      }
    }
  ]
}

Hiển thị QR trên PWA
Dùng trực tiếp giá trị:

students[0].qr.payload

để tạo ảnh QR bằng thư viện QR của PWA.

Mã QR được tự động tạo ở lần đầu gọi API và được lưu cố định. Những lần gọi sau sẽ trả lại cùng một mã, không cần API tạo mới.

Không nên log hoặc gửi token QR ra nơi khác.

2. Staff quét mã QR
Endpoint
GET /api/attendance-qr/scan/:token

Header
Authorization: Bearer <STAFF_JWT_TOKEN>

Staff PWA quét được giá trị:

qr.payload

Sau đó gọi:

GET /api/attendance-qr/scan/WJ8Fzv...raw-token...

Nếu QR chứa URL thay vì raw token, PWA cần lấy token từ query parameter:

/attendance/qr?token=WJ8Fzv...raw-token...

Response thành công
{
  "student": {
    "id": "student-uuid",
    "code": "HV-141",
    "fullName": "Nguyễn Thu Hiền 123"
  },
  "session": {
    "studentSessionId": "student-session-uuid",
    "classSessionId": "class-session-uuid",
    "classId": "class-uuid",
    "className": "IELTS 10",
    "classCode": "IELTS10",
    "sessionDate": "2026-09-19",
    "sessionIndex": 1,
    "startTime": "08:00",
    "endTime": "10:00",
    "teacherName": "Nguyễn Văn A",
    "attendanceStatus": "pending"
  },
  "attendance": {
    "canAttend": true,
    "displayFrom": "2026-09-19T00:45:00.000Z",
    "openAt": "2026-09-19T01:00:00.000Z",
    "latestAt": "2026-09-19T01:15:00.000Z"
  }
}

Ý nghĩa các trường thời gian
displayFrom: thời điểm lịch bắt đầu được hiển thị.
openAt: thời điểm nút điểm danh được phép hoạt động.
latestAt: thời điểm cuối được phép điểm danh.
canAttend:
true: được phép gọi API ghi nhận điểm danh.
false: hiển thị lịch nhưng khóa nút điểm danh.
Mặc định lịch QR được hiển thị trước giờ học 15 phút. Nếu cấu hình staff được điểm danh sớm hơn, displayFrom và openAt sẽ theo cấu hình đó.

Các mã lỗi
HTTP	Mã	Ý nghĩa
401	—	Chưa đăng nhập hoặc JWT không hợp lệ
403	—	Tài khoản không phải staff hoặc không có quyền cơ sở
404	NO_VISIBLE_SESSION	Hiện không có lịch phù hợp để điểm danh
404	—	QR không hợp lệ hoặc đã bị thu hồi
409	AMBIGUOUS_SESSION	Có nhiều lịch trùng thời gian
3. Staff ghi nhận điểm danh
Sau khi scan thành công, lấy:

session.studentSessionId
session.classSessionId

Sau đó gọi API mobile hiện có:

POST /api/mobile/staff/calendar/session/:classSessionId/attendance

Ví dụ:

POST /api/mobile/staff/calendar/session/class-session-uuid/attendance
Authorization: Bearer <STAFF_JWT_TOKEN>
Content-Type: application/json

Body:

{
  "studentSessionId": "student-session-uuid",
  "attendanceStatus": "present",
  "attendanceNote": "Điểm danh QR"
}

Response:

{
  "success": true
}

Nếu chưa đến openAt, API trả 403 và không ghi nhận điểm danh.

4. Luồng đề xuất cho staff PWA
1. Mở camera
2. Quét QR
3. Lấy raw token từ QR
4. GET /api/attendance-qr/scan/:token
5. Hiển thị học viên, lớp, ca học, giáo viên
6. Nếu attendance.canAttend = false:
   - Khóa nút
   - Hiển thị "Điểm danh mở lúc HH:mm"
7. Nếu attendance.canAttend = true:
   - Cho phép bấm Điểm danh
8. POST /api/mobile/staff/calendar/session/:classSessionId/attendance
9. Gửi studentSessionId và attendanceStatus = "present"

Đã kiểm tra các endpoint không có JWT đều trả 401, workflow đang chạy và npm run build thành công.
