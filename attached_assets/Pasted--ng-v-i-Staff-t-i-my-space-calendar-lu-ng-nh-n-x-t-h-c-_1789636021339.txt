Đúng, với Staff tại /my-space/calendar, luồng nhận xét học viên dùng các API sau.

1. Luồng Web Staff hiện tại
Bước 1: Lấy danh sách lịch dạy của nhân viên
GET /api/my-space/calendar/staff?month=YYYY-MM

Ví dụ:

GET /api/my-space/calendar/staff?month=2026-09

Response có các buổi học:

2. Lấy danh sách tiêu chí và giáo viên
Để dựng form nhập nhận xét, Web Staff dùng:

GET /api/evaluation-criteria

API trả danh sách bộ tiêu chí và các tiêu chí con. Cấu trúc cần dùng:

[
  {
    "id": "criteria-uuid-1",
    "name": "Thái độ học tập",
    "subCriteria": [
      {
        "id": "heading-uuid",
        "name": "Tập trung trong giờ học",
        "parentId": null,
        "itemType": "heading",
        "inputType": "text"
      },
      {
        "id": "sub-criteria-uuid-1",
        "name": "Chú ý nghe giảng",
        "parentId": "heading-uuid",
        "itemType": "criterion",
        "inputType": "checkbox"
      },
      {
        "id": "sub-criteria-uuid-2",
        "name": "Chủ động phát biểu",
        "parentId": "heading-uuid",
        "itemType": "criterion",
        "inputType": "text"
      }
    ]
  }
]

Quy tắc:

itemType: "heading" là tiêu đề nhóm.
itemType: "criterion" là tiêu chí thực tế để nhập.
inputType: "checkbox" là checkbox Đạt/Chưa đạt.
inputType: "text" là ô nhập nhận xét.
parentId trỏ đến tiêu đề nhóm.
Danh sách giáo viên trong buổi học được trả trong API:

GET /api/my-space/calendar/staff/session/:classSessionId

Field:

"teachers": [
  {
    "id": "teacher-uuid",
    "fullName": "Nguyễn Thị B",
    "code": "GV001"
  }
]

3. Lưu nhận xét Web Staff
Endpoint
POST /api/student-sessions/review

Body
{
  "studentSessionIds": [
    "student-session-uuid"
  ],
  "published": true,
  "reviewData": {
    "teacher-uuid": {
      "teacherName": "Nguyễn Thị B",
      "items": [
        {
          "criteriaId": "criteria-uuid-1",
          "criteriaName": "Thái độ học tập",
          "subCriteriaId": "sub-criteria-uuid-1",
          "subCriteriaName": "Chú ý nghe giảng",
          "groupName": "Tập trung trong giờ học",
          "inputType": "checkbox",
          "checked": true,
          "comment": ""
        },
        {
          "criteriaId": "criteria-uuid-1",
          "criteriaName": "Thái độ học tập",
          "subCriteriaId": "sub-criteria-uuid-2",
          "subCriteriaName": "Chủ động phát biểu",
          "groupName": "Tập trung trong giờ học",
          "inputType": "text",
          "comment": "Có tiến bộ"
        }
      ],
      "criteriaRatings": {
        "criteria-uuid-1": 4
      }
    }
  }
}

Response thành công
{
  "success": true
}

Ý nghĩa published
"published": true

Lưu nhận xét.
Công khai cho học viên/phụ huynh.
Gửi thông báo nhận xét mới.
"published": false

Lưu nhận xét nháp.
Học viên/phụ huynh chưa nhìn thấy.
Không gửi thông báo công khai.

5. Quy tắc dữ liệu nhận xét mới
Bộ tiêu chí
{
  "criteriaName": "Thái độ học tập",
  "criteriaRatings": {
    "criteria-uuid-1": 4
  }
}

criteriaRatings phải dùng ID của bộ tiêu chí làm key:

{
  "criteria-uuid-1": 4
}

Không dùng tên làm key:

{
  "Thái độ học tập": 4
}

Tiêu chí checkbox
{
  "subCriteriaName": "Chú ý nghe giảng",
  "inputType": "checkbox",
  "checked": true,
  "comment": ""
}

checked: true → Đạt.
checked: false → Chưa đạt.
Tiêu chí text
{
  "subCriteriaName": "Chủ động phát biểu",
  "inputType": "text",
  "comment": "Có tiến bộ"
}

Nhóm tiêu chí
{
  "groupName": "Tập trung trong giờ học"
}

Các item cùng groupName thuộc cùng một nhóm. Khi render không được lặp tiêu đề nhóm cho từng item.

Tóm tắt cho bên Web Staff
Bên Web Staff cần dùng chuỗi API:

GET  /api/my-space/calendar/staff?month=YYYY-MM
GET  /api/my-space/calendar/staff/session/:classSessionId
GET  /api/class-sessions/:classSessionId/student-sessions
GET  /api/evaluation-criteria
POST /api/student-sessions/review

Trong đó API quan trọng nhất khi bấm nhận xét một học viên là:

GET /api/class-sessions/:classSessionId/student-sessions

để lấy studentSessionId, reviewData, reviewPublished, sau đó lưu bằng:

POST /api/student-sessions/review
