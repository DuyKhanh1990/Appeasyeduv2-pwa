Đã đầy đủ về mặt key

Resource	Số key

Invoices	31

Cơ chế đổi ngôn ngữ hiện tại
MY SPACE không có API riêng để đổi ngôn ngữ.

Frontend hiện dùng:

localStorage.setItem("app_lang", "vi");
// hoặc
localStorage.setItem("app_lang", "en");
Giá trị mặc định là vi.

PWA nên triển khai tương đương:

type Language = "vi" | "en";
const lang = localStorage.getItem("app_lang") === "en"
  ? "en"
  : "vi";
API backend hiện trả về dữ liệu nghiệp vụ, không dịch theo Accept-Language hay query lang.

Vì vậy:

Nhãn giao diện: PWA tự dịch bằng resource vi/en.
Trạng thái API: PWA map enum sang ngôn ngữ tương ứng.
Tên lớp, tên học viên, nội dung bài tập, nhận xét, mô tả: giữ nguyên dữ liệu người dùng nhập.
Không được dịch các enum trước khi gửi ngược lên API.
2. Cách xác thực API
Các API MY SPACE hiện dùng session đăng nhập của hệ thống.

PWA cần gửi cookie session:

fetch(url, {
  credentials: "include",
});
Nếu PWA chạy khác origin/domain, cần dùng cùng cơ chế proxy hoặc cấu hình CORS/cookie phù hợp. Không có JWT language token riêng cho MY SPACE.

Mã phản hồi phổ biến:

Status	Ý nghĩa
200	Thành công
201	Tạo mới thành công
204	Thành công, không có response body
400	Dữ liệu gửi lên không hợp lệ
401	Chưa đăng nhập
403	Không có quyền hoặc sai loại tài khoản
404	Không tìm thấy dữ liệu
409	Xung đột nghiệp vụ
500	Lỗi server

10. Khuyến nghị gửi cho đội PWA
Đội PWA nên tách thành ba lớp:

A. API client
Giữ nguyên enum/API values:

status = "present";
itemType = "exam";
invoiceType = "income";
leaveType = "nghi_phep";
B. Translation resources
Dùng key tương tự hiện tại:

t("mySpace.calendar.attendancePresent");
t("mySpace.assignments.submit");
t("mySpace.invoices.summary.income");
t("mySpace.payroll.netPay");
C. Enum display mapping
Ví dụ:

const attendanceLabels = {
  vi: {
    present: "Có học",
    absent: "Nghỉ học",
    makeup_wait: "Nghỉ chờ bù",
  },
  en: {
    present: "Attended",
    absent: "Absent",
    makeup_wait: "Absent, makeup pending",
  },
};
Hiện tại backend chưa có cơ chế trả dữ liệu nghiệp vụ theo lang=vi/en. Nếu PWA cần dùng chung resource dịch với web, nên export/import bộ resource client/src/i18n/my-space/ thành package hoặc JSON dùng chung, thay vì gọi một API dịch riêng.
